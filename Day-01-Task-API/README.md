# 📌 Day 01 - Express Task API

## 📖 Overview

This project is my first backend application built using **Node.js** and **Express.js**.

It demonstrates how to build a simple REST API that performs CRUD (Create, Read, Update, Delete) operations using an in-memory array.

---

## 🚀 Features

- Get all tasks
- Get task by ID
- Create a new task
- Update an existing task
- Delete a task

---

## 🛠️ Tech Stack

- Node.js
- Express.js
- JavaScript

## 📡 API Endpoints

| Method | Endpoint | Description |
|---------|----------|-------------|
| GET | `/tasks` | Get all tasks |
| GET | `/tasks/:id` | Get task by ID |
| POST | `/tasks` | Create a new task |
| PUT | `/tasks/:id` | Update a task |
| DELETE | `/tasks/:id` | Delete a task |
